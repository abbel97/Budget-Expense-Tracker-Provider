# expense_tracker

A new Flutter project.

## 📌 Features

- Add new expenses/Incomes
- View list of all expenses
- Edit existing expenses/Incomes
- Delete expenses/Incomes
- Simple summary of transactions

## API

This project uses MockAPI as the backend service.
